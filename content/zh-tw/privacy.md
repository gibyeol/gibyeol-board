## Nadri 蒐集的資料

Nadri 沒有帳號或電子報,也不會設定自己的 Cookie。

- **意見表單。** 如果你用頁面最下方的「告訴我們」表單送出意見,我們會把你寫的內容、選的類別、你是從哪一頁(哪種語言)送出的,以及收到的時間,存放在 Nadri 於 GitHub 的私人儲存庫。我們不會要你的姓名或電子郵件,也不會保存你的 IP 位址。請不要在內容中寫個人資料。如需刪除你送出的內容,請寫信到下方的聯絡信箱。

## 會看到你造訪紀錄的服務

- **垃圾訊息檢查。** 你打開意見表單時,Cloudflare Turnstile 會在瀏覽器中確認你是不是真人,為此會檢查瀏覽器環境的資訊。Cloudflare 表示 Turnstile 不會讀取、保存或傳送表單內容。詳情:[Turnstile 隱私權附錄(英文)](https://www.cloudflare.com/turnstile-privacy-policy/)。
- **主機代管。** 本網站由 Cloudflare 提供,Cloudflare 會處理標準的請求資料(例如你的 IP 位址),以傳送網頁並阻擋濫用行為。
- **字型。** 字型由本網站自行提供,不會有字型服務得知你的造訪。
- **造訪統計。** 我們使用 Cloudflare Web Analytics 統計頁面瀏覽量、來源網站和國家,不使用 Cookie,也不建立個人檔案。Nadri 只看得到總數。
- **聯盟行銷連結指令碼。** 只有標示聯盟行銷說明的頁面(機場、eSIM、購物等 12 頁),而且要在 Cookie 提示中按下「同意」之後,才會載入 Travelpayouts(我們的旅遊聯盟行銷網路)的指令碼,它會把部分旅遊連結轉換成聯盟行銷連結,並計算這些連結的點擊次數。它可能會在你的瀏覽器中儲存一個小型識別碼,用來認列訂單。
- **購物聯盟腳本。** 同樣這 12 頁也會載入 Skimlinks 的腳本,把部分商店連結轉成聯盟連結並計算點擊;為記錄購買,可能在瀏覽器存放小型識別碼。健康與緊急狀況頁面不會載入。
- **由你決定。** 上述聯盟腳本只有在你於 Cookie 說明中點「同意」後才會載入;拒絕或瀏覽器傳送 Global Privacy Control 訊號時不會載入。[重新選擇 Cookie 設定](#consent-reset)
- **聯盟行銷合作夥伴。** 當你點擊聯盟行銷連結時,聯盟網路(例如 Awin、Travelpayouts)和合作夥伴網站(例如 Klook、Yesim、Stylevana)可能會記錄點擊並設定 Cookie 來認列轉介。進入對方網站後,即適用該網站自己的隱私權政策。
