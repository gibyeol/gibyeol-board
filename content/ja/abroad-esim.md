## ひと目で判断

| こんな人 | 選ぶもの | 理由 |
|---|---|---|
| スマホがeSIM対応で、SIMロックもない | eSIM | 出発前に家でインストールし、着いたらオンにするだけ。今使っているSIMは挿したまま |
| スマホがeSIM非対応 | 現地SIM | SIMを差し替える手間だけ |
| 短い出張で、自分の番号で電話・SMSを受け続けたい | 携帯会社のローミング | 設定がいちばん簡単。料金は出発前に携帯会社のアプリで必ず比較 |

eSIMが楽な理由はシンプルです。SIMピンも、小さなSIMをなくす心配もなく、今使っているSIMはスマホに入れたまま、データだけ現地のものを使う仕組みだからです。

## 条件1:スマホがeSIMに対応しているか

**iPhone。** iPhone XS、XS Max、XR以降のモデルはeSIMに対応しています。例外(Apple):中国本土でeSIMに対応しているのはiPhone 18 Pro・18 Pro Max・iPhone Duo・17e・iPhone Airのみ。香港・マカオには2枚のnano-SIMを使うデュアルSIMのiPhoneモデルがあります。そこで買ったiPhoneなら、まずモデルを確認してください。

**Galaxy。** 韓国でeSIMの開通が始まったのは2022年9月1日で、韓国向けで最初のeSIM対応モデルはGalaxy Z Fold4・Z Flip4でした。それより前に出た韓国向けモデルは対応していない可能性が高いので、モデル名で推測せず、次の方法で直接確かめるのが確実です。

- Galaxy:**設定 → 端末情報 → ステータス情報**に**EID**の項目があればeSIM対応です。
- iPhone:XS・XR以降なら対応なので、モデルだけ確認すれば大丈夫です(中国本土・香港・マカオのモデルは上の例外を参照)(**設定 → 一般 → 情報 → モデル名**)。

## 条件2:SIMロックがかかっていないか

他社のeSIMを使うには、スマホが特定の携帯会社にロックされていないことが必要です。EIDが表示されても、ロックがあると海外のeSIMが使えないことがあります。

- iPhone:**設定 → 一般 → 情報 → SIMロック**に「SIMロックなし」と表示されれば合格です。
- Galaxyには同じメニューがないので、携帯会社で買ったスマホなら、出発前にその会社のカスタマーセンターにロックの有無を聞くのがいちばん早いです。

## 2つの条件を満たしたら

出発の1〜2日前に、家のWi-Fiでインストールまで済ませておくのがおすすめです。

1. 行き先の国と期間に合うデータプランを選ぶ
2. 受け取ったQRコードかアプリでeSIMをインストールする(インストールだけ、まだオンにしない)
3. 着いたらeSIMの回線をオンにし、その回線でデータローミングを許可する
4. 普段使っているSIMの回線はデータをオフにする(ローミングのデータ料金がかからないように)

<details class="tr-more"><summary><i class="ic ic-list-checks" aria-hidden="true"></i>機種別のタップ順(Apple・Samsungの公式案内)</summary>

**iPhone**

1. **インストール(家のWi-Fiで):** カメラアプリでQRコードをスキャン →「モバイル通信プランが検出されました」の通知をタップ → 画面下の「続ける」→「モバイル通信プランを追加」。メールやブラウザで届いたQRは長押しして「eSIMを追加」。リンクで届いたら、リンクをタップ →「許可」→「続ける」。
2. **着いたらオン:**「旅行用のeSIMをオンにする」の通知が出たらタップ →「旅行用eSIMのみ」か「旅行用eSIMと現在のeSIM」を選ぶ →「続ける」(iOS 26以降)。通知がなければ**設定 →「モバイル通信」→「モバイルデータ通信」**で旅行用eSIMの回線を選びます。データ通信は一度に1つの番号だけです。
3. **旅行用eSIMのデータローミングをオン:** **設定 →「モバイル通信」→ 旅行用eSIMの番号**をタップして「データローミング」をオンに(上のリストの3)。データローミングは、契約中の通信会社のネットワーク外でモバイルデータ通信を使ってインターネットにつなぐためのスイッチです。販売元の案内が違う場合はそちらに従ってください。
4. **普段のSIMのローミング料金を防ぐ:** 2回線ともオンだと、自分の国の回線でローミング料金が発生する可能性があります。**設定 →「モバイル通信」→ 普段の番号**をタップして「データローミング」をオフに。普段の番号にかかってくる電話・SMSの料金は、出発前に通信会社に確認してください。
5. **帰国したら:** iOS 26以降は国や地域によって、旅行用eSIMが自動でオフになり普段のSIMがオンに戻ります。通知がなければ**設定 →「モバイル通信」**で普段の番号の「この回線をオンにする」がオンか確認し、使い終わった旅行用eSIMの回線はオフに。
6. **つながらないとき:** 機内モードをオン・オフ → 設定 →「モバイル通信」でその回線をオフ・オン → 再起動。それでもだめなら販売元へ(画面のエラーメッセージとEID:設定 → 一般 → 情報)。

**Galaxy**(メニュー名は機種やソフトウェアで少し違います)

1. **インストール(家のWi-Fiで):** **設定 → 接続 → SIMマネージャー → eSIMを追加 → QRコードをスキャン** → 届いたQRをスキャン。コードで届いたら同じ画面で「有効化コードを入力」。
2. **着いたらオン:** **設定 → 接続 → SIMマネージャー**で旅行用eSIMのスイッチをオンにし、モバイルデータを旅行用eSIMにします。
3. **データがつながらないとき:** **設定 → 接続 → モバイルネットワーク → データローミング**がオンか確認。グレーならモバイルデータを先にオンに。
4. **帰国したら:** SIMマネージャーでモバイルデータを普段のSIMに戻し、旅行用eSIMはオフに。
5. **それでもだめなら:** 再起動してから販売元へ。
