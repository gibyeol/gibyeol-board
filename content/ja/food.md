## 焼肉の夜

私たちのおすすめの夜です。焼肉店では炭火のグリルがテーブルに埋め込まれていることがあります。椅子にふたがあれば開けてみてください。上着に料理のにおいが移らないようにした収納椅子です。スプーン・箸・ナプキンはテーブルの小さな引き出しに、店員を呼ぶ呼び出しボタンもあります。KTOによると、その音は思ったより大きいかもしれません。

店員が肉を焼いてくれる店もあり、焼けたと言われたら葉野菜で包んで(サム)食べます。追加したいときは「ヨギヨ!」(すみません!)と声をかければ大丈夫。締めくくりはKTOが挙げるとおり、テンジャンチゲ(味噌チゲ)かポックンパ(焼き飯)にしました。

## ひとことで言うと

| 場面 | どうするか | 理由 |
|---|---|---|
| さっと昼ごはん、ひとりでも | キンパ店、チゲ定食、麺・クッパの店 | 1人前が基本で、ひとり客も普通です |
| 焼肉の夜 | 2人以上で行くか、入る前に「1인분 돼요?」 | テーブルで焼く肉は2人前からの店があります |
| 夜、ホテルで | 配達アプリ「배민(ペミン)」 | JCBもApple Payで使え、韓国の電話番号も不要に |
| ベジタリアン・ハラール・アレルギー | 注文前に韓国語の一文を見せる | だしや魚醤、アミの塩辛が見えないところに入っています |

選んだのは3つ。予約は**NAVERマップ**、夜は**배민**、食べられないものがあれば下の**カード**。外したのは人気店ランキングと、旅行者が使えるか確認できなかった予約アプリです。何でも食べられて、指さしで頼むのが平気な方には不要なページです。チップ(不要)と2人前のルールは[韓国の生活マナー](/ja/everyday/)に詳しく書きました。

## 場面別の定番

料理はKTOの料理ページから選びました。KTOは料理ごとに「ふつう入っているもの」も書いていて、苦手なものがあるなら説明よりそちらが大事です。

**さっと昼ごはん。** キンパ(ふつうハム・卵・ツナ入り)とキムチチゲ(ふつう豚肉かツナ入り)が定番。麺やクッパの店もひとりで入りやすいです。

**焼肉の夜。** サムギョプサルは豚バラの焼肉。タッカルビは鶏肉とキャベツ、さつまいも、トッポッキの餅を大きな鉄板で炒める料理で、同じ流れです。プデチゲはテーブルに大鍋ひとつ。

**市場と屋台。** トッポッキ(ふつう練り物入り)、スープに浸けたおでん串、ティギム(天ぷら。トッポッキのたれにつけて)、黒糖・シナモン・ナッツ入りのホットク、ケランパン(卵が丸ごと入ったパン)、あんこ入りのたい焼き風プンオパン(魚は入っていません)。小さな屋台は日本のカードが通らないことがあるので、小額のウォン札を。[韓国のお金](/ja/money/)も参考に。

**夜遅く。** 配達(下)か[コンビニ](/ja/convenience-store/)。

## 注文のしかた

テーブルのタブレットや入口のキオスクで注文し、先に支払いまでする店が増えています(The Korea Herald 2024年1月、KTO)。どのタイプの店かがわかれば、あとは流れに乗るだけです。

{{fig:food-2|注文と支払い、3つのパターン}}

- **タブレット・キオスク:** 韓国語だけの画面ならPapagoのカメラをかざして。
- **店員に注文:** 用があるときは呼び出しボタン。
- **スプーンと箸**はテーブルの引き出しに。箸が難しければスプーンを使っても大丈夫とKTO。
- **水とおかずのおかわりは無料**とKTO。セルフコーナーの店もあります。
- **支払い:** タブレットはたいてい注文時に。そうでなければ帰りにレジで([韓国の生活マナー](/ja/everyday/))。

## 予約と行列:NAVERマップ

NAVERは2026年6月4日から、旅行者向けのパスポート認証を始めました。日本のパスポートでスマホから認証でき、韓国の電話番号もカスタマーセンターへの連絡もいりません。認証するとNAVERマップで予約・注文・支払いができます。海外発行カードでの予約・決済を受けるかは店ごとに決めます(The Korea Herald 2026年7月)。すべての店で使えるわけではありません。

{{fig:food-3|旅行者がNAVERマップで予約する流れ}}

確認できなかったこと: NAVERの順番待ち機能が含まれるか、CatchTableやTablingを旅行者が使えるか。入口に紙の名簿やタブレットがあれば、名前を書いて近くで待ちましょう。

## 配達アプリ:배민(ペダルの民族)

배민(ペダルの民族)は2026年、旅行者が使いやすくなる変更が3つありました。

- **言語:** 2月から日本語・英語・中国語。スマホの言語設定に合わせて切り替わります。
- **カード:** 6月2日から、日本で発行したJCB・Visa・Mastercard・アメックスをApple Payで。海外のクレジットカード、WeChat Pay、Alipay+にも対応。
- **韓国の番号なし:** 7月下旬から、決済に韓国の携帯契約が不要に。日本の携帯番号に届くSMSで認証します。

{{fig:food-4|ホテルから배민で注文する}}

コツ: 注文前にNAVERマップでホテルの韓国語住所をコピーし、配達の受け取り場所をフロントで聞いておきましょう。

## ベジタリアン・ヴィーガン

聞くまではベジタリアン料理ではないと考えましょう。KTOのベジタリアン向けガイドが挙げる落とし穴: キムチには塩辛や魚醤が入ることが多く、スンドゥブチゲや豆腐の煮物にはふつうアミの塩辛が入ります。ビビンバは肉と卵がのることが多く、野菜キンパにもハム・卵・カニカマが入ることがあります。KTOがすすめる比較的安全なものは、野菜キンパ(要確認)、どんぐりのムッ和え(トトリムクムチム)、豆腐料理、肉を使わない精進料理(寺院料理)です。[KTOのベジタリアン向けガイド](https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=140732)(英語)。

## ハラール

KTOの[ムスリムフレンドリー旅行のページ](https://english.visitkorea.or.kr/svc/thingsToDo/subMuslimFriendly.do)は、飲食店を4段階に分けています。

| 表示 | 意味 |
|---|---|
| ハラール認証 | 韓国イスラム教中央会などの機関による認証 |
| 自己認証 | ムスリムの店主がすべての料理をハラールと認証 |
| ムスリムフレンドリー | ハラールの料理が一部あり、お酒を出すことも |
| ポークフリー | ハラールメニューはなく豚肉もなし、お酒を出すことも |

KTOは、ムスリムフレンドリーと表示したホテルのビュッフェでも豚肉料理が並ぶことがあると注意しています。同じページにムスリムフレンドリーの飲食店電子ブック(2022年版)があります。

## アレルギー

アレルギー表示の義務は一部のチェーンだけです。2021年7月から、ハンバーガー、ピザ、パン、アイスクリームなどを売る50店舗以上のブランドは、卵、牛乳、そば、落花生、大豆、小麦、えび、かに、豚肉など22品目を表示します。小さな店にはこうした表示がありません。アレルギーが重い方は、原材料が書かれた店を選び、薬を持ち歩いてください。

### 見せるカード(読まずに見せてください)

| 日本語 | 韓国語 |
|---|---|
| ___アレルギーがあります。 | 저는 ___ 알레르기가 있어요. |
| これに___は入っていますか? | 이 음식에 ___ 들어가요? |
| ___を抜いてください。 | ___ 빼 주세요. |
| ベジタリアンです。/ ヴィーガンです。 | 저는 채식주의자예요. / 저는 비건이에요. |
| 肉、魚、卵、牛乳を食べません。 | 고기, 생선, 달걀, 우유를 안 먹어요. |
| スープに肉やいりこは入っていますか? | 국물에 고기나 멸치가 들어가요? |
| 豚肉は入っていますか? | 돼지고기 들어가요? |
| 落花生 / ナッツ類 / えび / かに / 貝類 / 卵 / 牛乳 / 小麦 / そば / 大豆 | 땅콩 / 견과류 / 새우 / 게 / 조개류 / 달걀 / 우유 / 밀 / 메밀 / 콩 |

出発前にこのカードをスクリーンショットしておくと、通信なしでも開けます。もっと込み入った話は、日本語も通じる1330観光案内電話が通訳してくれます。詳しくは[韓国の生活マナー](/ja/everyday/)で。
