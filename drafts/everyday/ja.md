## 初めてだと驚くこと

| 場面 | どうするか | 理由 |
|---|---|---|
| 会計でチップを置くか迷う | 表示価格だけ払えばOK | チップの習慣はなく、メニュー価格は税・サービス料込みと法律で決まっている |
| ひとりで焼肉を食べたい | 入る前に1人前でいいか確認 | 2人前以上の注文を求める店がある |
| 店員さんが来ない | テーブルの呼び出しボタンを押す | どのテーブルにもあり、店員はそれを待っている |
| 夜に日本語で助けが必要 | 1330に電話(深夜0時まで) | 日本語を含む8言語で通訳・案内 |
| 充電器のプラグが合わない | 丸ピン2本の変換プラグを持参 | 韓国は220V・60Hz |
| 飲み終えたカップを捨てたい | コンビニや駅まで持ち歩く | ソウル市内の街頭ゴミ箱は約7,100個しかない |
| 地下鉄でピンクの席が空いている | 座らずに空けておく | 妊婦さんのための席 |

いちばん大事なのは3つ。チップは不要、1330の番号、変換プラグ。それ以外は、事前に準備するというより知っておけば困らないマナーです。

## チップ:日本と同じで不要

韓国観光公社は「韓国ではチップは必要なく、期待もされていない」と明記しています。2013年の食品衛生法改正で、飲食店は税金とサービス料を含めた最終価格を表示する決まりになっていて、メニューの値段がそのまま支払額です。

最近、一部のカフェがチップ瓶やタブレットのチップ選択を置いて話題になりましたが、韓国の客の反応はおおむね否定的でした。置いてあっても任意です。タクシーもメーター料金で、チップは不要です(韓国観光公社)。

## ひとりご飯(ホンバプ)と2人前ルール

ひとりで食べることは「혼밥(ホンバプ)」と呼ばれ、ごく普通のことです。韓国では単身世帯が全世帯の36.1%(2024年、国家データ処)を占め、2024年の生活時間調査では昼食・夕食のおよそ4回に1回がひとりでした。麺や汁物、キンパの店、フードコート、コンビニは気軽に入れます。

例外は、テーブルで焼いたり煮たりして分け合う料理です。焼肉や鍋の店では、ひとり客に2人前の注文を求める店があると多くの旅行者が報告しています。2025年11月には「ひとり客お断り」の貼り紙が韓国のSNSで話題になり、批判が多く集まりました。とはいえ決めるのはお店なので:

- メニューに「2인분 이상」(2人前以上)とあれば、それが店のルールです。
- 座る前に確認を。Papagoで「1인분 돼요?」(1人前でもいいですか)と見せれば伝わります。

## 飲食店の基本

- **水は無料。** 壁際のウォーターサーバーや冷蔵庫からセルフで取る店が多いです。おかずのおかわりも無料(韓国観光公社)。
- **呼び出しベル。** どのテーブルにもボタンがあります。観光公社いわく、音は思ったより大きめです。
- **支払い。** 最近はテーブルのタブレットや入口のキオスクで注文と支払いを先に済ませる店が増えています。店員に注文して伝票が来ない場合は、テーブルの伝票を持って出口のレジへ。
- **カード** はほぼどこでも使えます。JCBの使い勝手は[韓国のお金](/ja/money/)で。

## 日本語・英語はどこまで通じるか

ホテルや空港ではたいてい対応してもらえますが、タクシーや小さな食堂では韓国語だけということもよくあります。英国政府も、タクシー運転手は英語を「ほとんど、またはまったく話さない」ことが多いとしています。行き先は韓国語で見せられるようにしておくのが確実です。

- Papago:メニューはカメラで、短い会話は音声で。
- NAVERマップ:日本語表示にして、韓国語の住所を画面で見せる。
- 込み入った話は **1330 観光案内電話**(下記)に日本語で。

## 治安と、女性のひとり旅

韓国は比較的安全な旅行先です。米国務省は渡航勧告をいちばん低いレベル1とし、カナダ政府も2026年10月の更新で外国人を狙った犯罪は全般に少ないとしています。

各国政府が共通して挙げる注意点はこちら:

- **繁華街の夜。** カナダ政府は、梨泰院・江南・弘大などのバー周辺で性的暴行やハラスメントが「珍しくない」と注意しています。飲み物から目を離さず、知り合ったばかりの人からの飲み物は受け取らないこと。
- **アプリで知り合った相手。** 米国務省によると、若い女性の被害の多くはSNSやマッチングアプリで知り合った相手によるもので、飲酒が絡むことが多いそうです。
- **タクシー。** 正規のタクシーか、カカオTなどの配車アプリを使う。
- **スリ。** 混雑した市場や観光地で。

治安が良いぶん、つい気が緩むこと。注意すべきなのは、ほぼそれだけです。

### 保存しておきたい番号

| 番号 | 用途 | 言語 |
|---|---|---|
| 112 | 警察 | 英語・中国語は24時間通訳あり。日本語は外部通訳経由 |
| 119 | 消防・救急 | |
| 1330 | 観光案内・通訳・苦情 | 日本語を含む8言語 |
| 1366 | DV被害の相談電話(24時間) | |

1330は韓国観光公社の運営で、韓国語・英語・日本語・中国語・ロシア語・ベトナム語・タイ語・マレー語/インドネシア語に対応。毎日7時〜24時、緊急機関との三者通話で通訳もしてくれます。韓国内からは1330、海外からは+82-2-1330。Webチャット、カカオトーク、LINE、Facebook、WhatsAppでも相談でき、Wi-Fiでの無料ネット通話は[公式ページ(英語)](https://english.visitkorea.or.kr/svc/contents/contentsView.do?vcontsId=140632&menuSn=454)から使えます。緊急時はまず112・119へ。日本語が通じず困ったら、1330の三者通話を頼る手もあります(7時〜24時)。

## 電圧と変換プラグ

韓国は220V・60Hz、コンセントは丸い穴が2つ(一般にC・Fタイプと呼ばれる形)。日本の平たいプラグはそのままでは挿さらないので、変換プラグが必要です。スマホやPCの充電器は表示に「100-240V」とあれば変換プラグだけでOK。日本国内専用(100V)のドライヤーやヘアアイロンは変圧器が必要なので、持って行かないほうが無難です。観光公社によると、変換プラグはホテルのフロントで借りられることがあり、仁川空港のコンビニや免税店でも売っています。

## お酒・たばこは何歳から

韓国では誕生日ではなく生まれ年で数え、19歳になる年の1月1日から購入できます。2026年は2007年生まれ以前、2027年は2008年生まれ以前です。韓国では身分証の携帯が法律上の義務なので、パスポートを持ち歩いてください。

## 喫煙

2015年から、飲食店・カフェ・バーは規模にかかわらず屋内全面禁煙です。ソウルでは地下鉄出入口から10m以内、バス停、南山や汝矣島などの市立公園、江南大路などの路上も禁煙。違反は最大10万ウォンの過料で、2026年4月24日からは合成ニコチンの液体電子たばこも対象になりました。喫煙ブースを探しましょう。

## ゴミ箱が少ない理由

1995年にゴミ袋有料制が始まり、家庭ゴミが街頭のゴミ箱に捨てられるようになったため、ソウル市はゴミ箱を減らしました。観光客の増加を受けて2023年から増設中ですが、2026年9月時点で7,142個と、1995年の数にはまだ届いていません。コンビニや駅で捨てるつもりで、ゴミは持ち歩くのが基本です。分別の口があれば分けて入れましょう。

## 地下鉄のマナー

- **ピンクの席** は妊婦さん用(1両に2席)。混んでいても空けておくのがおすすめです。
- **車両の両端の席** は高齢者・障がいのある人の優先席。
- **車内は静かに。** 通話は小声で短く、というのがソウル市が昔から呼びかけてきたマナーです。

何度も韓国に来ている方は、1330の番号だけ保存しておけば十分です。
