## (a) GitHub Actions(공개 사이트 저장소, 무료)가 자동으로 가져올 수 있는 것
오늘 robots가 허용하고 이 환경에서 열린 곳만 후보다.
- CJ 뉴스룸 `post-sitemap7.xml`(lastmod): 새 글 감지. 하루 2회.
- 다이소 다이소소식 목록: 하루 1회.
- Korea Herald `sitemap/latest-articles`: 제목이 들어 있어서 키워드 감지에 쓴다. Korea Times sitemap도 같이. 하루 2~4회.
- 비짓코리아 영문, 서울시 뉴스: 하루 1회.
- 쓰는 곳: `data/shop-raw/<날짜>/<출처>.json`에 **추가만** 한다(제목·URL·날짜·본문 발췌 해시). `data/shop-trends.json`과 큐레이션 문장은 절대 고치지 않는다.
- 막힌 곳(올리브영·무신사·YesStyle·Stylevana): 자동 대상에서 뺀다. 우회하지 않는다.
- 미확인: proxy-403인 국내 언론·쿠팡·공공 API가 GitHub Actions에서 열리는지. 약관 확인과 함께 다음 단계에서 본다.

## (b) Claude 큐레이션
- 주기: 하루 1회(안). 새 원자료가 있을 때만 돈다.
- 순서: 새 원자료 읽기 → 이전 판(shop-storyboard)과 비교 → 바뀐 키워드만 고침 → 신호(근거 수) 다시 계산 → 만료된 코드·혜택 내림.
- 토큰 추정: **다음 단계에서 근거를 붙여 쓴다.** 오늘은 근거 없이 숫자를 적지 않는다.

## (c) 원두가 해야 하는 것 (자동 경로가 없는 것만)
- 올리브영 앱 랭킹, 무신사 앱 랭킹, 2025 올리브영 어워즈 부문별 수상 목록: 휴대폰 화면 캡처. 주 1회 안.
- 제휴 가입: storyboard의 '판에서 도출 2' 표가 후보 목록이다.

## (d) 화면에서 신선도 보여 주기
- 항목마다 `checked`(확인한 날)를 둔다. 코드·혜택은 `end`(마감일)를 두고, 마감이 지나면 자동으로 내린다(deals.json과 같은 방식).
- 근거 수가 1인 키워드에는 '한 출처 보도'라고 표시한다.

## (e) 위험
- 약관: robots 허용과 약관 허용은 다르다. 오늘 약관 원문은 하나도 읽지 않았다.
- 지난 코드: 무신사 코드는 11/24 확인분이고, 오늘 재확인하지 못했다.
- 저작권: 쇼핑몰·브랜드 상품 사진은 쓰지 않는다. 기사 본문은 인용 범위로만 쓴다.

## 키워드 갱신 방법 (명세 8, 다음 단계에서 상세화)
- 새 관심 키워드 감지: 공식 보도자료 제목에서 기획전명이나 트렌드 명명('프로 셀프케어', '서바이벌 뷰티', '홈스파' 등)을 뽑는다. 영문 언론 최신 사이트맵 제목도 본다. 두 곳 이상에서 나오면 후보로 올린다.
- 주기: 감지는 하루 1회. 키워드 추가·삭제는 Claude가 제안하고, 판에 반영한다.
- 사라진 키워드: 4주 동안 새 근거가 없으면 '지난 키워드'로 내린다(안).
